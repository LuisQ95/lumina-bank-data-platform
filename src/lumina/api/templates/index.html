Reglas de decisión que aplica Dataflow
  • Riesgo = 0.08 × transacciones del último minuto + 0.45 si el GPS está en otro distrito + 0.4 × monto / 25,000.
  • Riesgo de 0.65 o más: REVISION_FRAUDE.
  • Acumulado del día mayor que el límite del cliente: RECHAZADA_LIMITE.
  • Un id de transacción repetido se descarta en Redis con SET NX y no llega a BigQuery.
